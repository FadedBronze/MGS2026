# What I did implemented three different spell types:

Boomerang: bounces off the wall and has to be picked up

Pea Shooter: does some damage and disappears on enemy collision

Bomb: goes "up" and damages surrounding tiles

I implemented these using classes for each one and they inherited from the existing entity class. 
I also create a manager class for all of to trigger on key press events and a central place to add new spells.
